# NextPlay Solutions

The canonical website for [NextPlay Solutions](https://nextplaysolutions.ai): AI business optimization and implementation for small and mid-sized businesses.

The offer is defined centrally in `lib/offer.ts` so page copy, structured data, pricing, and AI-readable content stay aligned. Scout provides a free 25-minute business assessment and written report. Paid implementation starts at $2,500 for One Play, $5,000 for The Roadmap, with custom scopes quoted privately.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.
